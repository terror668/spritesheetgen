MCP サーバー + CLI

コーディングエージェントで 2D ゲームのスプライトシートを

Claude Code、Codex、Cursor にキャラクターと動きを伝えるだけ。SpriteSheetGen が生成し、スプライトシート、JSON アトラス、Godot の SpriteFrames ファイルをプロジェクトに置きます。

どれも SpriteSheetGen で作った歩きアニメーションです（騎士の画像はロゴのイラストで、アニメーションだけを生成）。

セットアップ ブラウザで試す

セットアップ

  1. エージェントにインストールさせる。Claude Code、Codex など MCP 対応のエージェントにこう送ります： 
    SpriteSheetGen をセットアップして：https://spritesheetgen.com/agents/install.txt の手順に従って
    MCP サーバーと、ツールの使い方・予算・エンジンへの取り込みを知っているスキルが追加されます。
  2. アカウントページで API キーを作成します。キーごとに権限と 1 日・合計のクレジット上限があり、許可するまで新しいキーは消費できません。
  3. ご自身のターミナルでログインします。チャットには貼らないでください（入力は表示されません）： 
    npx -y @spritesheetgen/cli login

MCP サーバーを手動で追加する

claude mcp add spritesheetgen -s user -- npx -y @spritesheetgen/cli mcp
codex mcp add spritesheetgen -- npx -y @spritesheetgen/cli mcp
{
  "mcpServers": {
    "spritesheetgen": {
      "command": "npx",
      "args": ["-y", "@spritesheetgen/cli", "mcp"]
    }
  }
}

Node.js 20 以上が必要です。サーバーは stdio で動き、login で保存したキー（または SPRITESHEETGEN_API_KEY）を読むので、あとからログインしても再起動は不要です。

ツール

ツールクレジット内容
estimate_sprite無料キャラクターや動作の価格、残高、キーの残り予算を確認
improve_prompt無料ざっくりしたアイデアを生成しやすいキャラクター説明に整える（1 日の無料回数あり）
create_character有料説明からキャラクター画像を 1 枚生成
upload_character無料手持ちの PNG・JPEG・WebP のキャラクターを使う
animate_character有料アニメーションを 1 つ生成：walk、run、idle、attack、jump
get_generation無料生成の状態と結果を確認（完了まで待つことも可能）
list_characters無料生成またはアップロードしたキャラクターの一覧
list_actions無料キャラクターが持っているアニメーションの一覧（二重払いを防ぐ）
export_sprite_sheet無料完成したアニメーション（または手元の GIF）をローカルのフォルダに書き出す

エージェントはまず見積もりを出し、あなたが了承してから消費します。有料の呼び出しには必ず max_credits の上限と client_key が付くので、再試行しても二重に請求されません。新規アカウントには 25 クレジット。最新の価格は料金ページへ。エンジンへの読み込み手順を含む完全なガイドは spritesheetgen.com にあります。

CLI

MCP なしでも同じ機能が使えます。スクリプト向けに --json 出力もあります：

spritesheetgen estimate --description "a small beetle knight" --json
spritesheetgen character --description "a small beetle knight" --client-key my-key-0001 --max-credits 5 --json
spritesheetgen animate --reference generation:CHARACTER_ID --action walk --client-key my-key-0002 --max-credits 10 --json
spritesheetgen export --id ANIMATION_ID --out ./assets/beetle-walk --name walk --individual-frames --preview --json

手持ちの GIF の書き出しはキー不要・無料です：

npx -y @spritesheetgen/cli export --file ./walk.gif --out ./assets/walk --name hero_walk --preview

書き出されるファイル

サンプル：グリーンバックの騎士の歩きを CLI で書き出したもの（背景除去、エッジ処理、フレーム位置合わせ）。

ファイル使い道
sheet.pngどのエンジンでも：フレームを 1 行またはグリッドに並べた透明 PNG
sheet.jsonPhaser、PixiJS など TexturePacker JSON（hash）を読むエンジン（animations 付き）
animation.tresGodot 4：AnimatedSprite2D 用の SpriteFrames リソース（速度とループ設定済み）
preview.gifすぐに確認するためのプレビュー
export.json使った設定（同じ書き出しを繰り返すため）
frames/*.pngUnity、GameMaker など単体画像を使うツール（--individual-frames）

Phaser 3

this.load.atlas("knight", "sheet.png", "sheet.json");
this.anims.create({
  key: "walk",
  frames: this.anims.generateFrameNames("knight", { prefix: "knight_walk_", end: 11, zeroPad: 2 }),
  frameRate: 14,
  repeat: -1,
});

Godot 4

sheet.png と animation.tres を同じフォルダに置き、AnimatedSprite2D を追加して、その Sprite Frames に animation.tres をドラッグします。

エージェントなしならブラウザで

ここまでの機能はすべて spritesheetgen.com でも使えます。端末内で動く無料ツールもあります：動画からスプライトシート、GIF からスプライトシート、スプライトシート作成、スプライトシート分割、スプライトシートから GIF。
