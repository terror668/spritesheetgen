MCP server + CLI

AI sprite sheets for 2D games, from your coding agent

Ask Claude Code, Codex or Cursor for a character and its moves. SpriteSheetGen generates them and drops a sprite sheet, a JSON atlas and a Godot SpriteFrames file into your project.

Walk cycles made with SpriteSheetGen (the knight's image is our logo art; only its animation is generated).

Set it up Try it in the browser

Setup

  1. Let your agent install it. Paste this into Claude Code, Codex or another agent with MCP: 
    Set up SpriteSheetGen for me: follow https://spritesheetgen.com/agents/install.txt
    It adds the MCP server and an agent skill that knows the tools, budgets and engine imports.
  2. Create an API key on the account page. Each key has its own permissions and a daily and total credit cap; a new key cannot spend until you allow it.
  3. Log in from your own terminal, not the chat (the key is typed hidden): 
    npx -y @spritesheetgen/cli login

Or add the MCP server by hand

claude mcp add spritesheetgen -s user -- npx -y @spritesheetgen/cli mcp
codex mcp add spritesheetgen -- npx -y @spritesheetgen/cli mcp
{
  "mcpServers": {
    "spritesheetgen": {
      "command": "npx",
      "args": ["-y", "@spritesheetgen/cli", "mcp"]
    }
  }
}

Node.js 20 or newer. The server talks over stdio and reads the key saved by login (or SPRITESHEETGEN_API_KEY), so logging in later needs no restart.

Tools

ToolCreditsWhat it does
estimate_spritefreePrice of a character or an action, your balance and the key's remaining budget
improve_promptfreeTurns a rough idea into a character description that generates well (small daily quota)
create_characterpaidOne character image from a description
upload_characterfreeUses your own PNG, JPEG or WebP character instead
animate_characterpaidOne animation: walk, run, idle, attack or jump
get_generationfreeStatus and result of a generation; can wait for it
list_charactersfreeCharacters you generated or uploaded
list_actionsfreeAnimations a character already has, so you never pay twice
export_sprite_sheetfreePacks a finished animation, or a local GIF, into a folder on your machine

Your agent estimates first, shows you the price and spends only after you say yes. Every paid call carries a max_credits cap and a client_key, so a retried request is never charged twice. New accounts receive 25 credits; current prices are on the pricing page.

CLI

The same features without MCP, with --json output for scripts:

spritesheetgen estimate --description "a small beetle knight" --json
spritesheetgen character --description "a small beetle knight" --client-key my-key-0001 --max-credits 5 --json
spritesheetgen animate --reference generation:CHARACTER_ID --action walk --client-key my-key-0002 --max-credits 10 --json
spritesheetgen export --id ANIMATION_ID --out ./assets/beetle-walk --name walk --individual-frames --preview --json

Packing a GIF you already have needs no key and costs nothing:

npx -y @spritesheetgen/cli export --file ./walk.gif --out ./assets/walk --name hero_walk --preview

What an export contains

The sample export: the knight's walk on a green screen, packed by the CLI (background removed, edges cleaned, frames aligned).

FileUse it in
sheet.pngAny engine: frames in a row or a grid, transparent background
sheet.jsonPhaser, PixiJS and other engines that read TexturePacker JSON (hash), with an animations block
animation.tresGodot 4: a SpriteFrames resource for AnimatedSprite2D, with speed and looping set
preview.gifA quick look
export.jsonThe settings used, to repeat the export
frames/*.pngUnity, GameMaker or any tool that wants single images (--individual-frames)

Phaser 3

this.load.atlas("knight", "sheet.png", "sheet.json");
this.anims.create({
  key: "walk",
  frames: this.anims.generateFrameNames("knight", { prefix: "knight_walk_", end: 11, zeroPad: 2 }),
  frameRate: 14,
  repeat: -1,
});

Godot 4

Put sheet.png and animation.tres in the same folder, add an AnimatedSprite2D and drag animation.tres onto its Sprite Frames property.
