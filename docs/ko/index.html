MCP 서버 + CLI

코딩 에이전트로 만드는 2D 게임 스프라이트 시트

Claude Code, Codex, Cursor에 원하는 캐릭터와 동작을 말하면 SpriteSheetGen이 만들어 스프라이트 시트, JSON 아틀라스, Godot SpriteFrames 파일을 프로젝트에 넣어 줍니다.

모두 SpriteSheetGen으로 만든 걷기 애니메이션입니다(기사 이미지는 로고 그림이고, 애니메이션만 생성했습니다).

설치하기 브라우저에서 써 보기

설치

  1. 에이전트에게 설치를 맡기세요. Claude Code, Codex 등 MCP를 지원하는 에이전트에 이 문장을 보내세요: 
    SpriteSheetGen을 설정해 줘: https://spritesheetgen.com/agents/install.txt 의 단계를 따라 줘
    MCP 서버와 함께 도구 사용법, 예산, 엔진 가져오기를 아는 스킬이 설치됩니다.
  2. 계정 페이지에서 API 키를 만드세요. 키마다 권한과 하루·전체 크레딧 한도가 있고, 허용하기 전까지 새 키는 크레딧을 쓸 수 없습니다.
  3. 내 터미널에서 로그인하세요. 채팅에 붙여 넣지 마세요(입력 내용은 보이지 않습니다): 
    npx -y @spritesheetgen/cli login

MCP 서버를 직접 추가하기

claude mcp add spritesheetgen -s user -- npx -y @spritesheetgen/cli mcp
codex mcp add spritesheetgen -- npx -y @spritesheetgen/cli mcp
{
  "mcpServers": {
    "spritesheetgen": {
      "command": "npx",
      "args": ["-y", "@spritesheetgen/cli", "mcp"]
    }
  }
}

Node.js 20 이상이 필요합니다. 서버는 stdio로 동작하고 login으로 저장한 키(또는 SPRITESHEETGEN_API_KEY)를 읽으므로, 나중에 로그인해도 다시 시작할 필요가 없습니다.

도구

도구크레딧하는 일
estimate_sprite무료캐릭터나 동작의 가격, 잔액, 키의 남은 예산 확인
improve_prompt무료대략적인 아이디어를 잘 생성되는 캐릭터 설명으로 다듬기(하루 무료 횟수 있음)
create_character유료설명으로 캐릭터 이미지 1장 생성
upload_character무료직접 가진 PNG, JPEG, WebP 캐릭터 사용
animate_character유료애니메이션 1개 생성: walk, run, idle, attack, jump
get_generation무료생성 상태와 결과 확인(완료까지 기다릴 수 있음)
list_characters무료생성하거나 업로드한 캐릭터 목록
list_actions무료캐릭터가 이미 가진 애니메이션 목록(중복 결제 방지)
export_sprite_sheet무료완성된 애니메이션(또는 내 GIF)을 내 컴퓨터 폴더로 내보내기

에이전트는 먼저 가격을 알려 주고, 동의한 뒤에만 크레딧을 씁니다. 유료 호출에는 항상 max_credits 한도와 client_key가 붙어서 다시 시도해도 두 번 청구되지 않습니다. 새 계정은 25 크레딧을 받습니다. 현재 가격은 요금 페이지에서 확인하세요. 엔진에 넣는 방법까지 담은 전체 안내는 spritesheetgen.com에 있습니다.

CLI

MCP 없이도 같은 기능을 쓸 수 있고, 스크립트용 --json 출력도 있습니다:

spritesheetgen estimate --description "a small beetle knight" --json
spritesheetgen character --description "a small beetle knight" --client-key my-key-0001 --max-credits 5 --json
spritesheetgen animate --reference generation:CHARACTER_ID --action walk --client-key my-key-0002 --max-credits 10 --json
spritesheetgen export --id ANIMATION_ID --out ./assets/beetle-walk --name walk --individual-frames --preview --json

가지고 있는 GIF를 내보낼 때는 키가 필요 없고 무료입니다:

npx -y @spritesheetgen/cli export --file ./walk.gif --out ./assets/walk --name hero_walk --preview

내보내기 결과물

예시 결과물: 그린 스크린 위 기사의 걷기를 CLI로 내보낸 것(배경 제거, 가장자리 정리, 프레임 정렬).

파일쓰는 곳
sheet.png모든 엔진: 프레임을 한 줄 또는 격자로 배치한 투명 PNG
sheet.jsonPhaser, PixiJS 등 TexturePacker JSON(hash)을 읽는 엔진(animations 포함)
animation.tresGodot 4: AnimatedSprite2D용 SpriteFrames 리소스(속도와 반복 설정 포함)
preview.gif빠른 미리 보기
export.json사용한 설정(같은 내보내기를 반복할 때)
frames/*.pngUnity, GameMaker 등 낱장 이미지가 필요한 도구(--individual-frames)

this.load.atlas("knight", "sheet.png", "sheet.json");
