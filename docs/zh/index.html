安装

  1. 让助手帮你装。把这句话发给 Claude Code、Codex 或其他支持 MCP 的助手： 
    帮我安装 SpriteSheetGen：按 https://spritesheetgen.com/agents/install.txt 的步骤操作
    它会添加 MCP 服务，并装好一份说明（skill），里面写了工具用法、额度规则和各引擎的导入方法。
  2. 在账户页创建 API 密钥。每个密钥有自己的权限和每日、总额度上限；新建的密钥在你允许之前不能消费积分。
  3. 在你自己的终端里登录，不要在聊天里粘贴（输入密钥时不会显示）： 
    npx -y @spritesheetgen/cli login

也可以手动添加 MCP 服务

claude mcp add spritesheetgen -s user -- npx -y @spritesheetgen/cli mcp
codex mcp add spritesheetgen -- npx -y @spritesheetgen/cli mcp
{
  "mcpServers": {
    "spritesheetgen": {
      "command": "npx",
      "args": ["-y", "@spritesheetgen/cli", "mcp"]
    }
  }
}

需要 Node.js 20 或更新版本。服务通过 stdio 通信，读取 login 保存的密钥（或环境变量 SPRITESHEETGEN_API_KEY），之后再登录也不用重启。

工具

工具积分作用
estimate_sprite免费查询生成角色或动作的价格、你的余额和密钥剩余额度
improve_prompt免费把粗略的想法改写成容易生成好的角色描述（每天有少量免费次数）
create_character付费根据描述生成一张角色图
upload_character免费改用你自己的 PNG、JPEG 或 WebP 角色图
animate_character付费为角色生成一个动作：walk（走）、run（跑）、idle（待机）、attack（攻击）或 jump（跳）
get_generation免费查看生成任务的状态和结果，可以等待完成
list_characters免费列出你生成或上传过的角色
list_actions免费列出角色已有的动画，避免重复付费
export_sprite_sheet免费把完成的动画（或本地 GIF）打包到你电脑上的文件夹

助手会先报价，经你同意后才消费积分。每次付费调用都带 max_credits 上限和 client_key，重试同一请求不会重复扣费。新账户赠送 25 积分，当前价格见价格页。完整指南（含导入引擎的步骤）在 spritesheetgen.com。

命令行

不用 MCP 也能用同样的功能，加 --json 方便脚本处理：

spritesheetgen estimate --description "a small beetle knight" --json
spritesheetgen character --description "a small beetle knight" --client-key my-key-0001 --max-credits 5 --json
spritesheetgen animate --reference generation:CHARACTER_ID --action walk --client-key my-key-0002 --max-credits 10 --json
spritesheetgen export --id ANIMATION_ID --out ./assets/beetle-walk --name walk --individual-frames --preview --json

打包你已有的 GIF 不需要密钥，也不花积分：

npx -y @spritesheetgen/cli export --file ./walk.gif --out ./assets/walk --name hero_walk --preview

导出的文件

示例导出：小骑士在绿幕上的行走动画，由命令行打包（去背景、清理边缘、对齐帧）。

文件用途
sheet.png任何引擎：帧排成一行或网格，透明背景
sheet.jsonPhaser、PixiJS 等读取 TexturePacker JSON（hash）的引擎，带 animations 段
animation.tresGodot 4：给 AnimatedSprite2D 用的 SpriteFrames 资源，已设好速度和循环
preview.gif快速预览
export.json本次使用的设置，方便重复导出
frames/*.pngUnity、GameMaker 等需要单张图片的工具（--individual-frames）

Phaser 3

this.load.atlas("knight", "sheet.png", "sheet.json");
this.anims.create({
  key: "walk",
  frames: this.anims.generateFrameNames("knight", { prefix: "knight_walk_", end: 11, zeroPad: 2 }),
  frameRate: 14,
  repeat: -1,
});

Godot 4

把 sheet.png 和 animation.tres 放在同一个文件夹，添加一个 AnimatedSprite2D，把 animation.tres 拖到它的 Sprite Frames 属性上。
